
这是一个简易的红中麻将摸牌以及模拟最优解的智能麻将模拟器。
用户可以通过执行简易的摸牌以及打出最优解的操作，观看在某种特定情况经ai推理下的最佳胡牌策略
## 功能介绍

- **发牌**：随机生成13张起手牌
- **摸牌**：从牌墙摸取一张牌，自动判定是否胡牌
- **打最优牌**：智能分析并推荐最优出牌策略，显示向听数变化和进张数
- **理牌/原序切换**：支持按花色分组排序显示或原始顺序显示手牌
- **新摸牌标识**：最新摸到的牌在手牌最右侧以额外间距隔开显示

## 分析能力

- 向听数计算（支持0~7向听）
- 听牌列表与胡牌概率
- 有效进张计算与进张概率
- 打牌建议排序（按向听数和进张数优先）

## 胡牌判定

- 平胡（含万能牌红中替换）
- 碰碰胡（含万能牌红中替换）
- 七对

## 红中万能牌规则

红中作为万能牌，可替代任意牌面组成胡牌型。针对多张红中场景，采用三层防护确保计算稳定：

1. **ComputeBudget**：递归步骤预算控制（上限10000步）
2. **HuCallLimiter**：胡牌判定调用次数限制（上限30000次）
3. **超时保护**：3秒超时自动降级终止

## 技术栈

- HarmonyOS NEXT SDK 6.0.2
- ArkUI / ArkTS
- 横屏固定显示
